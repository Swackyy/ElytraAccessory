# Elytra Accessory
Allows you to equip Elytras in an accessory slot, including modded Elytras

Contains a built-in Elytra Accessory Type data-pack

---
## Requirements (dependencies)
**This mod requires [Ohmega](https://github.com/Swackyy/Ohmega) version 1.5.x**
